# Аналіз та Звіт проєкту StoryFlow

## 1. Загальний огляд
**StoryFlow** — це веб-додаток для відстеження оновлень манґи та коміксів. Проєкт реалізований як Fullstack додаток із використанням сучасного JavaScript-стеку та повною контейнеризацією через Docker.

---

## 2. Технологічний стек

### Frontend (Клієнт)
- **React 19** + **Vite 8**
- **Vanilla CSS** для стилізації (компонентно-орієнтований підхід)

### Backend (Сервер)
- **Node.js 20** + **Express 5**
- **MongoDB** + **Mongoose** (керування даними)
- **JSON Web Token** та **Bcryptjs** (підготовлено для безпеки)

### Інфраструктура
- **Docker & Docker Compose**: Ізоляція сервісів `frontend`, `backend` та `mongodb`.
- **Persistent Volumes**: Збереження даних бази на хост-машині.

---

## 4. Реалізований функціонал: User CRUD

Нещодавно було реалізовано повний цикл керування користувачами через API.

### Ендпоінти (Base URL: `/api/users`):

| Метод  | Шлях       | Опис                          | Статус відповіді |
| :----- | :--------- | :---------------------------- | :--------------- |
| **POST**   | `/`        | Створення нового користувача  | 201 Created      |
| **GET**    | `/`        | Отримання списку всіх юзерів  | 200 OK           |
| **GET**    | `/:id`     | Отримання одного за ID        | 200 OK           |
| **PUT**    | `/:id`     | Оновлення (username, email)   | 200 OK           |
| **DELETE** | `/:id`     | Видалення користувача         | 200 OK           |

### Формат відповіді:
Усі відповіді повертаються у форматі JSON:
```json
{
  "success": true,
  "data": { ... }
}
```

## 5. Налаштування Docker

Проєкт запускається однією командою:
```bash
docker-compose up --build
```

**Порти:**
- Frontend: `http://localhost:5173`
- Backend: `http://localhost:5000`
- MongoDB: `mongodb://localhost:27017`

---

## 6. Деталі останніх змін (Реалізація CRUD)

1.  **Модель (`backend/models/User.js`)**: Створено схему з валідацією email, унікальними полями та автоматичною датою створення.
2.  **Роутер (`backend/routes/userRoutes.js`)**: Використано `express.Router` з асинхронною обробкою запитів (`async/await`) та блоками `try/catch` для безпеки.
3.  **Інтеграція (`backend/index.js`)**:
    - Підключено `express.json()` для парсингу тіла запитів.
    - Підключено маршрути: `app.use('/api/users', userRoutes);`.
    - Налаштовано підключення до бази даних через внутрішню мережу Docker (`mongodb://mongodb:27017/storyflow`).
