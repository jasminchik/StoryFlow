# Повний аналіз проєкту StoryFlow

## 1. Загальний огляд
**StoryFlow** — це масштабна Fullstack-платформа для читання та публікації манґи, манхви, коміксів, а також художньої літератури (фанфіків, книг). Проєкт поєднує в собі функціонал соціальної мережі для авторів та читачів, надаючи інструменти для управління контентом, взаємодії через коментарі та рейтинги, а також персоналізації досвіду користувача.

---

## 2. Технологічний стек

### Frontend (Клієнт)
- **React 19**: Сучасна бібліотека для побудови інтерфейсу.
- **Vite 8**: Високопродуктивний інструмент збірки.
- **React Router 7**: Навігація та керування маршрутами.
- **SCSS Modules**: Модульна стилізація для уникнення конфліктів класів та підтримки чистих стилів.
- **Lucide React & React Icons**: Набори іконок для UI.
- **Context API**: Керування темами (ThemeContext) та станом авторизації.

### Backend (Сервер)
- **Node.js (Express 5)**: Швидкий та мінімалістичний веб-фреймворк.
- **MongoDB + Mongoose**: NoSQL база даних для гнучкого моделювання контенту.
- **JWT (JSON Web Token)**: Безпечна аутентифікація.
- **Multer**: Завантаження та обробка медіа-файлів (обкладинки, сторінки розділів).
- **Cloudinary (опціонально)**: Інтеграція для хмарного збереження зображень.

### Інфраструктура та DevOps
- **Docker & Docker Compose**: Повна контейнеризація (frontend, backend, database).
- **Persistent Volumes**: Збереження даних бази та завантажених файлів незалежно від життєвого циклу контейнерів.
- **Scripts**: Наявність скриптів для сидування даних (`seeder.js`) та автоматичного завантаження контенту.

---

## 3. Архітектура та структура проєкту

### Frontend (`/frontend/src`)
- **`components/`**: Велика бібліотека UI-компонентів (Header, Sidebar, AuthModal, CommentSection, UpdatesGrid тощо). Використовується модульний підхід до стилів.
- **`pages/`**: Реалізовано понад 10 основних сторінок:
    - **Home**: Головна з оновленнями та популярним контентом.
    - **Catalog**: Фільтрація та пошук за всією базою.
    - **MangaDetails / FanficDetails**: Детальна інформація про твір.
    - **Profile**: Кабінет користувача з налаштуваннями.
    - **CreateManga / CreateFanfic**: Інструменти для авторів.
- **`context/`**: `ThemeContext` забезпечує підтримку Dark/Light тем.

### Backend (`/backend`)
- **`models/`**: Складна структура даних:
    - `User`: Дані користувачів, ролі (user, author, admin), аватари.
    - `Manga` & `Chapter`: Контент для читання зображень.
    - `Literature` & `LiteratureChapter`: Текстовий контент.
    - `Comment`: Система відгуків.
    - `Rating`: Оцінки творів.
    - `Announcement`: Оголошення від авторів або адміністрації.
- **`routes/`**: Розділені API-ендпоінти для кожної сутності.
- **`middleware/`**: `authMiddleware` для перевірки токенів та прав доступу (власник/адмін).

## 4. Ключовий реалізований функціонал

1.  **Система користувачів**: Реєстрація, логін, профілі, зміна налаштувань, завантаження аватарів.
2.  **Управління контентом (CMS)**: 
    - Повний CRUD для Манґи та Літератури.
    - Масове завантаження розділів.
    - Система модерації (статуси `pending`, `approved`, `rejected`).
3.  **Взаємодія**:
    - Система коментарів до творів.
    - Виставлення рейтингів (зірочки).
    - Список "Обране" (Favorites) та "Читаю зараз" (Reading Now).
4.  **Пошук та Навігація**: 
    - Глобальний пошук через `SearchOverlay`.
    - Категорії та теги (`TagCategories`).
    - Оновлення у реальному часі на головній.
5.  **Дизайн та UI**: 
    - Адаптивна верстка (Mobile First через `BottomNav`).
    - Динамічна зміна тем.
    - Скелетони та анімації завантаження.

---

## 5. Поточний стан та досягнення

На даний момент проєкт є **повністю функціональним MVP** (Minimum Viable Product) з високим рівнем готовності:
- Бекенд повністю покриває потреби фронтенду.
- База даних містить реальні або тестові дані завдяки сидерам.
- Інтерфейс виглядає сучасно, є логічно завершеним та інтуїтивно зрозумілим.
- Контейнеризація дозволяє розгорнути проєкт однією командою (`npm run docker:up`).

---

## 6. Рекомендації для подальшого розвитку

1.  **Оптимізація**: Додати кешування (Redis) для популярних запитів.
2.  **Сповіщення**: Реалізувати WebSockets для миттєвих повідомлень про нові розділи або відповіді на коментарі.
3.  **Мобільний додаток**: Використовуючи існуючий API, можна створити додаток на React Native.
4.  **Аналітика**: Додати панель адміністратора для відстеження статистики переглядів та активності користувачів.
